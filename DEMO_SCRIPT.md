# POLARIS demo script

About six minutes. Start the edge (8001), twin (8000), voice (8002), and UI (5173) before the room.

1. **Overview.** Let the boot line finish. Point at the link strip: Edge, Twin, Voice, WS. The map is Bharati and Maitri, about 3,100 km apart, commanded from Goa.
2. **Daily briefing.** Press Daily briefing. Polar speaks fuel, wind, and alerts. If the voice sidecar is down, the dock still answers from the live desk.
3. **Fleet.** Open Fleet. Read the one-line gap: which station is warmer, which has more fuel days. Select the station you will stress.
4. **Control.** Open Control. Inject **Forecast Incoming Blizzard**. Wait for severity to rise. Show the prescribed action and the regulation card under it (clause, document, excerpt).
5. **Approve.** Press Approve & Execute on hatch lockdown. The incident log should show the operator control and the severity change with UTC times.
6. **Analytics.** Open Analytics. Drag the playback slider off Live so the charts stop on the storm, then return it to Live. Show the fuel ruler and where the 15-day floor sits.
7. **Voice order.** Open the AI dock and use **August fifth**, then **SITREP**. August fifth is the 2018 Bharati blizzard replay. SITREP downloads the situation report.
8. **Close.** Return to Overview. If a service drops, the amber banner should say the link is interrupted or the last snapshot is being held, instead of a blank screen.

Keep the 3D view in frame, but do not linger on camera moves. The argument is the closed loop: weather in, SOP out, operator action logged.
