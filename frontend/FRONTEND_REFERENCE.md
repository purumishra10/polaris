## 2. Views & Navigation Structure

The frontend consists of three synchronized views accessible via hash routing (`#/`, `#/analytics`, `#/mission-control`):

### 1. Homepage (`Home.tsx`)
- **Visuals**: Photorealistic widescreen Antarctic station background (`/antarctica-bg.jpg`) with dark radial vignette and frosted glassmorphic panels.
- **Hero Display**: Station metadata (NCPOR Goa, SIH 2026), live telemetry KPI ticker (Habitat temp, fuel autonomy, wind speed, satellite latency).
- **Node Cards**:
  - **Bharati**: Active primary coastal promontory node (69°24'S, 76°11'E).
  - **Maitri**: Inland oasis node (70°46'S, 11°44'E), marked with standby advisory status.
- **Navigation CTAs**: One-click entry points into **Telemetry Analytics** and **Mission Control**.

### 2. Telemetry Analytics Tab (`Analytics.tsx`)
- **Embedded 3D Spatial Twin**: Live interactive 3D station model with OrbitControls, subsystem focus selection, and a **Thermal Infrared (IR) toggle**.
- **Fuel & Autonomy Analytics**:
  - Hero countdown card: **Days of Autonomy Remaining** with nominal / advisory / critical thresholds.
  - JET A1 storage capacity progress bar (0 to 600,000 L).
  - Live burn rate ($L/h$) area chart with 180 L/h warning line.
- **Microgrid Load Distribution**:
  - Stacked area chart showing **Essential Load** (180 kVA), **Science Load** (120 kVA), and **Comfort Load** (60–110 kVA) against the 600 kVA rated CHP generator capacity limit.
- **Thermal Envelope & Weather**:
  - Dual-line stream chart comparing **Habitat Internal Temperature** ($^\circ\text{C}$) vs **Extreme External Ambient Cold** ($^\circ\text{C}$).
  - Real-time heat loss ($kW$) tracking envelope insulation efficiency during gale-force winds.
  - Auxiliary heating ($kW$) and solar flux ($W/m^2$) daylight tracking.
- **Data Integrity**: Every widget displays `source: synthetic` and `confidence: modeled`.

### 3. Mission Control State Tab (`MissionControl.tsx`)
- **Primary 3D Command Viewport**: Full-height Three.js / React Three Fiber spatial twin with interactive subsystem pins for the Generator Block, Fuel Farm, Science Radome, and Habitation Pods.
- **Operational Mode Toggle**: Switch between **Real-Time Synced** and **Stress-Test Simulation**.
- **Anomaly Alert Header**: Powered by real Isolation Forest decision function score:
  - `NOMINAL` (Green `#10b981`) — Anomaly score $> 0$.
  - `ADVISORY` (Amber `#f59e0b`) — Minor parameter drifts.
  - `CRITICAL` (Pulsing Red `#ef4444`) — Wind $> 60\text{ kt}$, internal temp $< 16^\circ\text{C}$, or autonomy $< 15\text{ days}$.
- **SOP Prescriptive Mitigation Drawer**:
  - Displays deterministic actions generated by the backend SOP rule matrix.
  - One-click **"Approve & Execute Mitigation"** buttons that dispatch real `POST /api/station/controls` actuator commands.
- **Scenario Injection Tray (Pitch Demos)**:
  - **80-Knot Blizzard**: Ramps wind $> 80\text{ kt}$, drops ambient to $-36^\circ\text{C}$.
  - **Resupply Delay**: Simulates sea-ice blockage; drops autonomy $< 15\text{ days}$.
  - **Polar Night**: Drops solar flux to $0\text{ W}/m^2$, ambient to $-31^\circ\text{C}$.
  - **Nominal Reset**: Restores standard baseline conditions.

## 4. State Management (Zustand Store)

Located in `src/store/usePolarisStore.js`:

| State Field | Type | Description |
|---|---|---|
| `selectedStation` | `'BHARATI' \| 'MAITRI'` | Currently active research station |
| `selectedSubsystem` | `string \| null` | Subsystem focused in 3D (`'GENERATOR'`, `'FUEL_FARM'`, `'RADOME'`, `'HABITAT'`) |
| `isThermalView` | `boolean` | Toggles the 3D thermal infrared heat shader |
| `linkMode` | `'REALTIME' \| 'STRESS_TEST'` | Active data ingestion mode |
| `connection` | `{ status, latency_ms, last_update }` | Satellite link health status |
| `telemetry` | `Record<Station, StationTelemetry>` | Live telemetry payload per station |

### Key Store Actions:
- `setTelemetryPacket(packet)`: Consumes live WebSocket packet and updates store.
- `executeMitigation(actionText)`: Dispatches actuator updates to `POST /api/station/controls`.
- `triggerScenario(scenarioKey)`: Dispatches test events to `POST /api/scenario/inject`.
- `setSelectedStation(stationId)`: Synchronizes active physics profile via `POST /api/station/switch/{stationId}`.
